# 06.04 — Monétisation (gagner de l'argent avec sa map)

Optionnel : comment une map publiée peut **générer des revenus**. À lire **après** avoir une map qui marche.

## 💸 Le principe : Creator Economy / engagement payouts

Epic **redistribue une part de ses revenus** Fortnite aux créateurs d'îles populaires.
La rémunération dépend largement de l'**engagement** : le **temps de jeu cumulé** (player-minutes)
généré par ta map. Plus des joueurs **restent et reviennent**, plus la map peut rapporter.

> Les modalités exactes (pourcentages, formules, seuils) évoluent. Réfère-toi toujours
> aux **règles officielles à jour** du programme créateur Epic.

## 🧩 Ce qu'il faut généralement

- Être **éligible** au programme créateur / **Support-a-Creator** (statut créateur).
- Une **audience minimale** est souvent demandée pour Support-a-Creator
  (ex. un certain nombre d'abonnés sur YouTube/Twitch/X). Vérifie les conditions actuelles.
- Une map **publiée publiquement** et **conforme** aux règles.
- Respect des **règles anti-triche / anti-manipulation** des statistiques (les fraudes sont sanctionnées).

## 📊 Les leviers qui font la différence

| Levier | Effet |
|--------|-------|
| **Rétention** | Joueurs qui restent longtemps → plus de player-minutes. |
| **Rejouabilité** | Score, classement, questions aléatoires → les joueurs reviennent. |
| **Qualité / fun** | Maps soignées = meilleures notes = plus de visibilité. |
| **Vitrine** | Titre + vignette = taux de clic → plus de joueurs entrants. |
| **Mises à jour** | Contenu frais (nouvelles questions) relance l'intérêt. |

## 🚫 Ce qu'il ne faut PAS faire

- **Gonfler artificiellement** les stats (bots, AFK forcé…) → bannissement du programme.
- **Copier** la map d'un autre créateur.
- Utiliser des **assets/marques** sans droits.
- Mettre du **contenu trompeur** (vignette mensongère) → déceptions, mauvaises stats, sanctions.

## 🧭 Stratégie réaliste pour débuter

1. **D'abord la qualité** : une map fun et rejouable, pas l'argent.
2. **Publie, observe les stats, itère** (rétention, durée moyenne).
3. **Construis une audience** (vidéos de ta map, communautés quiz Fortnite).
4. Quand tu es **éligible**, active la monétisation et continue d'améliorer.

> 💡 La monétisation est la **conséquence** d'une bonne map, pas le point de départ.
> Concentre-toi sur l'expérience joueur ; les revenus suivent l'engagement.
