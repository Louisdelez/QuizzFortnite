# 06.03 — Publication de la map

Comment mettre ta map en ligne et obtenir un **code d'île** que tout le monde peut jouer.

## 🧾 Prérequis à la publication

- [ ] Compte Epic avec **2FA activée** (obligatoire).
- [ ] Avoir rejoint l'**Island Creator Program** (gratuit) — voir
      [`../01-prerequis/01-materiel-comptes.md`](../01-prerequis/01-materiel-comptes.md).
- [ ] Map **testée** et **optimisée** (dossiers `06/01` et `06/02`).

## 🚀 Étapes de publication (depuis UEFN)

1. **Sauvegarde** le projet (`Ctrl+S`).
2. Ouvre le menu de **publication** (Fortnite → Publish / Push).
3. Renseigne les **métadonnées** :
   - **Titre** clair et attractif (ex. « FORTNITE QUIZ — 4 PORTAILS »).
   - **Description** : règles, nombre de questions, thème.
   - **Tags / catégories** (quiz, trivia, puzzle…).
   - **Nombre de joueurs** (min/max).
4. Ajoute une **vignette** (thumbnail) **1920×1080** soignée — c'est ce qui donne envie de cliquer.
5. Configure les **réglages de jeu** (joueurs max, durée, etc.) si demandé.
6. **Soumets** pour la **revue de conformité** d'Epic (souvent **1 à 3 jours ouvrés**).
7. À l'approbation, tu reçois un **code d'île unique** `0000-0000-0000`.

## 🔁 Versions privées vs publiques

- Tu peux d'abord publier en **privé / test** pour valider sur le vrai client Fortnite,
  puis passer en **public**.
- Les **mises à jour** se republient : la nouvelle version remplace l'ancienne pour les joueurs.

## 🖼️ Soigner la « vitrine » (très important pour la visibilité)

- **Titre + vignette** = 90 % du taux de clic sur le Discover.
- Montre le **concept** (les 4 portails, une question) sur la vignette.
- Description **honnête** : promets ce que la map offre réellement (évite les déceptions → mauvaises stats).

## ⚖️ Règles à respecter (sinon refus de publication)

- **Contenu approprié** (pas de contenu interdit, respect des règles Epic).
- **Pas de marques/assets non autorisés** (attention aux images importées : droits d'usage).
- Respect des **limites techniques** (mémoire, performances).
- Une map **fonctionnelle** et **jouable** du début à la fin.

## 📈 Après la publication

- Surveille les **statistiques** (joueurs, temps de jeu, rétention) dans le portail créateur.
- **Itère** : corrige les bugs remontés, ajoute des questions, améliore le rythme.
- Communique (réseaux, communautés) pour les premiers joueurs — l'algorithme aime l'engagement initial.
