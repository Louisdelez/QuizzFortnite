# 01.01 — Matériel & comptes requis

Avant d'installer quoi que ce soit, vérifie que tu remplis les conditions.

## 💻 Matériel (PC requis pour UEFN)

UEFN est un logiciel **PC uniquement** (Windows ou macOS). Il ne fonctionne pas sur console.

| Composant | Minimum conseillé | Confortable |
|-----------|-------------------|-------------|
| OS | Windows 10/11 64-bit ou macOS récent | Windows 11 |
| Processeur | Quad-core récent | 6–8 cœurs |
| RAM | **16 Go** | 32 Go |
| Carte graphique | GPU dédié (GTX 1060 / équivalent) | RTX série récente |
| Stockage | **SSD** avec ~50–100 Go libres | SSD NVMe |
| Connexion | Internet stable (téléchargements + publication) | Fibre |

> 💡 Le **SSD est fortement recommandé** : UEFN demande de placer les projets sur SSD
> pour de bonnes performances. Évite de stocker tes projets sur un disque dur mécanique.

> ✅ Ton environnement actuel est **Windows 11** — parfait pour UEFN.

## 🔐 Comptes nécessaires

### 1. Compte Epic Games
- Crée/connecte un **compte Epic Games** : https://www.epicgames.com
- Active l'**authentification à deux facteurs (2FA)** : c'est **obligatoire** pour publier.

### 2. Epic Games Launcher
- C'est le logiciel qui installe Fortnite **et** UEFN.
- Téléchargement : https://store.epicgames.com/fr/download

### 3. Island Creator Program (pour publier)
- Programme **gratuit** à rejoindre pour pouvoir publier des îles publiques.
- Conditions typiques : avoir **18 ans ou plus** (ou l'âge légal applicable), un compte
  en règle, la 2FA activée, et accepter les accords créateurs.
- On le rejoint depuis le site développeur Fortnite / l'écran de publication d'UEFN.
- 👉 Tu peux **tout construire et tester sans** être inscrit ; l'inscription n'est requise
  qu'au moment de **publier** (voir [`../06-tests-publication/03-publication.md`](../06-tests-publication/03-publication.md)).

## 💰 Coût

- **Gratuit.** UEFN, Verse, la publication et l'Island Creator Program ne coûtent rien.
- Optionnel : certains assets premium sur **Fab** peuvent être payants (non nécessaires pour un quiz).

## 🌍 Compte créateur & monétisation (plus tard)

Pour **gagner de l'argent** avec ta map, il faut un statut de créateur éligible
(via le programme **Support-a-Creator**) — voir
[`../06-tests-publication/04-monetisation.md`](../06-tests-publication/04-monetisation.md).
Ce n'est **pas** nécessaire pour créer, tester et publier une map gratuite.
