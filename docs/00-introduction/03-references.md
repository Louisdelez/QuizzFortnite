## ⚠️ Avertissement sur l'API Verse

Les exemples de code Verse de cette documentation suivent les **patterns officiels** mais
l'API évolue à chaque version de Fortnite. **Avant de coder, vérifie** :
- la signature exacte des événements (ex. `InteractedWithEvent`, `AgentEntersEvent`) ;
- le nom des méthodes de device (ex. `Teleport`, `SetText`, `Enable`/`Disable`) ;

dans l'**API Reference Verse** officielle accessible depuis UEFN et le portail dev Epic.
